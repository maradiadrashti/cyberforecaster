================================================================================
          CYBERFORECASTER // AI-BASED NETWORK ATTACK FORECASTING SYSTEM
                      SYSTEM UNDERSTANDING & USAGE GUIDE
================================================================================

This document explains the architecture, real-time packet capture, the prediction logic, 
and the step-by-step pipeline of CyberForecaster.

--------------------------------------------------------------------------------
1.1 VALUE PROPOSITION & SYSTEM PURPOSE
--------------------------------------------------------------------------------
Unlike reactive firewalls and signature-based IDSes, CyberForecaster is designed to:
1. Be PROACTIVE: It forecasts the next stage in the MITRE ATT&CK Kill Chain before 
   a breach is completed by looking at historical multi-step traffic flow sequences.
2. Support COUNTERFACTUAL WHAT-IF TESTING: Security teams can run rollout simulations
   and observe predicted threat trajectories for multiple defense actions (Do Nothing,
   Rate Limit, Block Ports, Isolate Host).
3. Provide LIVE NETWORK INSPECTION: Deep packet capture directly on physical/Wi-Fi/VPN 
   interfaces via Npcap/Scapy with sub-millisecond bidirectional flow aggregation.

--------------------------------------------------------------------------------
1.2 HOW TO RUN & DEMO
--------------------------------------------------------------------------------
Step 1: Start the services
  - Run `.\start.ps1` (Windows PowerShell with Admin) or `sudo ./start.sh` (Linux).
  - The script starts the Capture & AI Engine (port 8080) and Vite Frontend (port 5173).
  - The dashboard automatically opens in your browser at http://127.0.0.1:5173.

Step 2: Explore the 3D Landing Page & SOC Dashboard
  - The landing page features a cybernetic 3D Spline interactive robot.
  - Clicking "GET STARTED" or "LAUNCH SOC CONSOLE" opens the real-time SOC interface.

Step 3: Live Traffic & Attack Forecasting
  - Live flows stream over WebSocket from `capture-service`.
  - Machine learning models in `models/` classify incoming flows (Random Forest) and 
    forecast future kill chain attack stages (PyTorch GRU World Model).
  - Real-time confidence metrics, entropy, and mitigation controls allow operators to
    intervene and defend against attacks.

--------------------------------------------------------------------------------
1.3 CLEAN REPOSITORY STRUCTURE
--------------------------------------------------------------------------------
- `capture-service/`: High-performance FastAPI capture server + live AI inference.
- `client/`: React 19 + Vite SOC Dashboard with Spline 3D Robot hero.
- `models/`: Production PyTorch GRU Stage Forecaster & Random Forest Flow Classifier.
- `training/`: Training pipelines and dataset scripts (CIC-IDS2017 & synthetic).
- `labeling/`: Data labeling and synthetic traffic generators.
- `start.ps1` / `start.sh`: 1-click launch scripts for Windows and Linux.
- `setup.ps1` / `setup.sh`: Automated dependency installation scripts.
